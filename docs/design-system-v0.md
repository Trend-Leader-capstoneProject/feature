React Native 기반 모바일 앱 ‘Trend Leader’의 UI/UX 아트 디렉션과 메인 화면을 설계해주시기 바랍니다.

## 1. 서비스 정의

Trend Leader는 단순 뉴스 앱이나 인기 검색어 순위 앱이 아니다.

사용자가 선택한 관심 분야를 기준으로 지금 떠오르는 트렌드를 발견하고, 트렌드의 유행 이유와 관련 키워드를 AI 분석으로 빠르게 이해하는 ‘개인화 트렌드 관측 도구’다.

핵심 기능은 다음과 같다.

* 관심 카테고리 기반 맞춤 트렌드
* 전체 최신 이슈
* 트렌드 순위와 변화
* AI 한 줄 요약
* 유행 이유
* 관련 키워드
* 출처 플랫폼
* 북마크

## 2. 디자인 명제

“흩어진 트렌드 신호를 포착하고, 사용자가 이해할 수 있는 정보로 편집한다.”

앱은 일반적인 콘텐츠 피드보다 ‘신호 관측판’과 ‘편집 매거진’의 중간 인상을 가져야 한다.

주요 시각 언어는 Signal Editorial이다.
정보 계층, 타이포그래피, 레이아웃은 편집 디자인을 따른다.

Trend Radar는 보조 시각 언어로만 사용한다.
순위 변화, 상승 신호, 신규 진입, 데이터 갱신 상태를 표현할 때만 사용한다.
배경 장식이나 전체 화면 테마로는 사용하지 않는다.

Signal Editorial이란 다음을 의미한다.

- 강한 타이포그래피 계층
- 비대칭 정보 배치
- 얇은 구분선
- 카드보다 섹션 중심의 구성
- 편집 기사와 데이터 목록 사이의 시각적 리듬
- 이미지보다 제목과 메타데이터 우선

Trend Radar란 다음을 의미한다.

- 순위 변화와 트렌드 강도를 시각적 신호로 표현
- 상승, 하락, 신규 진입 상태를 형태와 숫자로 구분
- 데이터 상태에만 제한적으로 선, 점, 펄스 표현 사용
- 의미 없는 배경 파동이나 장식은 사용하지 않음

## 3. 원하는 인상

* 빠르게 변화하는 정보
* 관측과 발견
* 편집된 정보
* 개인화된 시선
* 신뢰할 수 있는 분석
* 젊지만 가볍지 않은 분위기

## 4. 시각적 문법

* 이미지보다 트렌드 제목, 순위 변화, 요약을 우선한다.
* 주요 트렌드의 순위 숫자를 적극적인 그래픽 요소로 사용한다.
* 상승, 하락, 신규 진입 상태가 색상뿐 아니라 아이콘과 형태로도 구분되어야 한다.
* 모든 콘텐츠를 독립된 둥근 카드에 넣지 않는다.
* 얇은 구분선, 타이포그래피 크기 차이, 여백으로 정보 영역을 구분한다.
* 대표 트렌드 1개는 비대칭 대형 영역으로 강조한다.
* 그 아래 트렌드는 밀도 있는 편집형 목록으로 제공한다.
* AI 분석 영역은 일반 설명과 다른 시각 언어를 사용한다.
* AI 영역에는 작은 라벨, 인용선, 강조 배경 또는 편집 주석 형태를 사용할 수 있다.
* 플랫폼 출처는 작은 텍스트 라벨 또는 단색 아이콘으로 표시한다.
* 관련 키워드는 일반적인 pill 버튼을 반복하기보다 연결된 키워드 군집처럼 보이게 구성한다.
* 북마크 아이콘은 콘텐츠보다 과도하게 강조하지 않는다.

## 5. 레이아웃 원칙 

### 5-1. 기본 원칙

* 8pt spacing system을 기반으로 한다.
* 주요 화면 좌우 여백은 20px 내외로 한다.
* 한 화면에서 radius는 최대 두 종류만 사용한다.
* 큰 카드의 모서리는 지나치게 둥글게 만들지 않는다.
* 모든 요소를 중앙 정렬하지 않는다.
* 콘텐츠 흐름은 왼쪽 정렬을 기본으로 한다.
* 상단 영역을 불필요하게 크게 사용하지 않는다.
* 실제 서비스 수준의 데이터 밀도를 유지한다.
* 제목, 순위, 변화량, 설명, 출처를 3초 안에 파악할 수 있어야 한다.


### 5-2. 기기 접근성 기준

- Android 모바일을 우선 대상으로 한다.
- 기준 화면 너비는 360~412dp로 한다.
- Safe Area를 고려한다.
- 주요 터치 영역은 최소 44×44dp를 확보한다.
- 본문 텍스트는 14sp 미만으로 만들지 않는다.
- 상승·하락 상태는 색상만으로 구분하지 않고 아이콘과 부호를 함께 사용한다.
- 긴 한글 제목은 최대 두 줄로 제한하고 말줄임 처리한다.

## 6. 색상 방향

* 기본 배경은 순백색보다 약간 온도가 있는 밝은 중성색을 사용한다.
* 본문은 거의 검정에 가까운 색상을 사용한다.
* 브랜드 강조 색상은 한 가지를 중심으로 사용한다.
* 상승과 하락 상태 색상은 브랜드 색상과 분리한다.
* 그라데이션은 핵심 데이터 상태를 표현할 때만 제한적으로 사용한다.
* 보라색과 파란색 그라데이션을 기본 배경으로 사용하지 않는다.

## 7. 타이포그래피

* 제목은 개성이 있지만 본문 가독성을 방해하지 않는 산세리프 계열로 표현한다.
* 숫자와 순위 정보는 제목과 다른 무게 또는 폭을 사용해 구분한다.
* 화면 제목, 대표 트렌드 제목, 카드 제목, 요약, 메타데이터의 크기 체계를 명확히 정의한다.
* 모든 텍스트를 굵게 처리하지 않는다.

## 8. 메인 화면 정보 구조

1. 작은 날짜 또는 현재 관측 시점
2. “내 관심사에서 포착된 트렌드”라는 화면 제목
3. 관심 카테고리 전환 영역
4. 오늘의 강한 트렌드 1개
5. 순위 변화가 포함된 맞춤 트렌드 목록
6. 관심사 밖에서 크게 상승한 최신 이슈 1~2개
7. 하단 내비게이션

대표 트렌드에는 다음 정보가 포함되어야 한다.

* 순위
* 트렌드 제목
* 한 줄 요약
* 상승 또는 하락 변화
* 대표 카테고리
* 출처 플랫폼
* 수집 시점
* 북마크 상태

## 9. 금지 사항

* 모든 콘텐츠를 흰색 rounded card로 반복하지 않는다.
* 모든 컴포넌트에 그림자를 사용하지 않는다.
* glassmorphism을 사용하지 않는다.
* 의미 없는 블롭, 원형, 파동 장식을 추가하지 않는다.
* 이모지를 기능 아이콘으로 사용하지 않는다.
* 일반적인 금융 대시보드처럼 만들지 않는다.
* SNS 피드처럼 프로필 이미지와 게시물 카드 중심으로 만들지 않는다.
* 뉴스 앱 템플릿을 그대로 복제하지 않는다.
* Material Design 기본 컴포넌트를 그대로 배치한 인상을 피한다.
* 데이터가 없는 가짜 차트는 사용하지 않는다.
* 지나치게 넓은 빈 공간으로 실제 정보량을 줄이지 않는다.
* “안녕하세요, 사용자님” 같은 일반적인 환영 문구를 화면의 핵심 영역으로 만들지 않는다.
