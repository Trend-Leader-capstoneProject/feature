# Trend Leader MVP-A — 2인 운영 도상 검증 시나리오 v0.1

> 문서 상태: **합성 사례 기반 예상 결과 / 실제 테스트 미실행**  
> 작성일: 2026-11-03 (KST)  
> 사용 목적: G4 카드 및 G5·G6 Batch 장부에 적용할 판단 순서를 사전에 검토  
> 실제 Google RSS 요청·실제 기사 링크 검증·실 DB/앱 게시·G6 승인 **모두 수행하지 않음**  
> 근거: `Google_Trends_RSS_운영_Gate_통과기준_검증증거_v0.3_POLICY_CONFIRMED.md` G4~G6, AT-10~AT-16.

## 0. 준비와 증거 한계

- 아래 Trend는 **허구의 제품과 사건**을 이용한 테스트 시나리오다. 실데이터를 반영하지 않으며 해당 내용의 진실성이나 이용 권한을 증명하지 않는다.
- 링크는 실제 주소를 제공하지 않는다. 어떤 예시에서 '링크 검증 완료'라고 가정하는 것은 **실제 HTTP 테스트 성공이 아닌 가정**이다.
- 운영 담당자 구성: 동료 팀원 1명은 검토·고위험 분류 논의; 사용자는 기능·콘텐츠 최종 승인 및 G6 운영 승인 예정.
- G6는 현재 `HOLD`다. 따라서 **실제 게시 가능 항목과 무관하게 실제 게시 수행은 0건**이다.

## 2. G4 카드 사용 예시: DEMO-001 (가상)

```yaml
card_id: G4-DEMO-001
trend_ref: DEMO-001
profile: MVP-A
title: "가상 게임 A 업데이트 공개"
description: "팀이 작성한 가상 설명문; 실제 기사에서 복제하지 않음"
source_url: "<가상 원문 — 실제 URL 없음>"
source_rights_evidence: "<테스트 가정; 실증거 없음>"
source_url_verification: "ASSUMED_FOR_PAPER_TEST_ONLY"
from_live_google_rss: false
risk_class: GENERAL_ELIGIBLE  # 시나리오상 가정
g4_result: HOLD                # 실제 검증 근거 없으므로 HOLD
content_approval: PENDING      # 실제 승인 수행하지 않음
approved_content_ref: null
batch_eligible_in_real_ops: false
```

**핵심:** 시나리오가 적격 경로를 설명하더라도 실제 링크·권리·사실관계·승인 증거가 없으면 G4 `PASS`가 아니다.

## 5. 실제 수동 검증을 시작할 때 기록할 항목

| 실측 항목 | 실제 확인 결과 (작업 전 빈칸) | 필요한 증거 |
|---|---|---|
| 출처·권리가 확인된 실제 샘플 확보 | **미확인** | G0 Source Scope, 근거 URL·확인일 |
| 팀 자체 작성 설명과 원문 링크 QA | **미검증** | G4 카드, 실제 링크 열람 기록 |
| Google RSS 비이용 | **미검증** | G1~G3 N/A: 설정·실행·DB/로그/앱 응답 검토 |
| 승인·미승인 데이터 게시 차단 | **미검증** | G5 실제 동작/수동 운영 기록 |
| 변경된 콘텐츠 게시 차단 | **미검증** | AT-14 테스트 결과 |
| 일부 실패 시 동작 | **미검증** | AT-15, 실제 트랜잭션 구조 확인 |
| 오류·권리 요청에 따른 개별 비노출 | **미검증** | AT-16 운영 리허설 |
| G6 최종 운영 승인 | **HOLD** | G6 승인자·증거·범위·시각 |

## 6. 수동 검증의 완료 기준

1. 실제 데이터로 검토할 때는 각 Trend의 **실제** 취득·권리·링크 증거를 남긴다.
2. 2인 팀의 고위험 분류/역할 배분을 실제 기록으로 검증한다.
3. Batch 편입과 내용 변경 여부를 실제 승인 대상과 대조한다.
4. G5 미승인 게시 차단·공개중단 경로가 실제로 존재하고 작동하는지 확인한다. 없으면 `HOLD` 및 후속 설계 필요로 기록한다.
5. G6 승인 전에 G0·G4·G5 증거, Google RSS G1~G3 N/A 증명, 사고 처리 담당자를 확인한다.
6. 실데이터 없이 합성 시나리오만으로는 실제 Gate `PASS` 또는 앱 기능 완료 판정을 내리지 않는다.

## 7. 현 시점의 결정과 영향

- 이번 문서는 **운영 절차 시뮬레이션을 위한 입력 자료**다. 실제 도상 회의를 팀원과 실시했다는 사실도 아직 없다.
- 실험·시연 중 외부 RSS 자동 요청, 원문 복제, 운영 DB 저장·앱 자동 게시는 하지 않는다.
- 기존 v0.3 정책, 프로젝트 코드/API/DB, GitHub/Notion, RSS P0~P3 FROZEN 계약은 변경하지 않는다.
