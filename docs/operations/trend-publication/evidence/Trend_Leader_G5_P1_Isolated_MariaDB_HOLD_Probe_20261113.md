## 3. 원본 증거 및 변경 관리

- 로컬 실행 도구: 기존 **G5 P1 MariaDB HOLD Probe**를 보완·재사용. 사용자 로컬의 백업·diff·실측 JSON은 별도 보관되며 **이 GitHub 체크포인트에 첨부하지 않았다**.
- 실행 당시 로컬 Probe의 최종 파일 SHA-256은 이 기록에서 **독립 확인되지 않았다**. 이전 보완 단계의 해시를 최종 실행본의 해시로 재사용하지 않는다.
- 인증 비밀번호·전체 DSN·실제 GRANT 원문·개별 행·로컬 개인 경로 등 비공개 자료는 GitHub에 업로드하지 않는다.
- 기존 공용 임시 인증정보 파일은 실행 후 **미사용·미삭제**로 보고되었다. 사용 여부와 안전한 정리 여부는 별도 로컬 확인 대상이며 이 체크포인트가 자동 삭제를 승인하지 않는다.
