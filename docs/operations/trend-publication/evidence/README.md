# 검증 증거 보존 가이드

> 이 문서는 검증용 인덱스의 관리 규칙입니다. 실제 Gate 승인 문서는 아닙니다.

- Evidence ID, 원본 보존 위치 또는 비밀이 아닌 참조값, 실행 환경, 시험/검토 시각, 책임자, 정책 버전, 변경 식별값, 재검토 조건을 연결합니다.
- 합성·오프라인/SQLite/격리 MariaDB/서비스 DB/실기기 시험을 구분하며 한 시험의 PASS를 운영 Gate PASS로 일반화하지 않습니다.
- 공개 GitHub 저장소에 실제 비밀번호, API Key, 토큰, 승인 서명, 비공개 회신 본문, 실제 운영 개인정보 및 상세 인증정보를 업로드하지 않습니다.
- 증거가 검증되기 전에는 `HOLD`와 `REVIEW_ONLY` 상태를 유지합니다.
