## D. Batch 실행 직전 체크리스트 — G5

- [ ] G6가 해당 환경/이용 범위에 대해 실제 PASS이고 승인 근거가 유효하다.
- [ ] Google RSS의 라이브 요청·저장·파생 데이터 게시가 실제로 사용되지 않음을 확인했다.
- [ ] Batch 항목 전부에 개별 G4 검토 카드·승인 증거가 있다.
- [ ] 고위험 유지, 증거 부족, 권한 없음 항목은 포함되지 않았다.
- [ ] 게시할 제목·자체 설명·카테고리·원문 링크 등이 승인 시점과 동일하다.
- [ ] Source Card에 권한 미확인 원제목·원문·이미지·자동 미리보기가 포함되지 않는다.
- [ ] 최종 운영 승인자/게시 담당자, 실패 시 중단 책임과 연락 경로를 확인했다.
- [ ] 공개중단·삭제 대응 경로 및 게시 후 수정 시 재검증 절차를 점검했다.
- [ ] 해당 실제 환경의 게시 실행·오류 처리 방식(전체 실패/부분 반영)을 확인했다.

## H. 2인 팀 사용 순서

1. 동료 팀원과 중요한 출처·사실관계 또는 고위험 의심 항목을 함께 논의한다.
2. 기능·콘텐츠 승인 담당자가 각 G4 카드에 최종 판정·승인을 기록한다.
3. Batch 장부에 **승인된 일반 콘텐츠만** 담고 변경 여부를 다시 확인한다.
4. G6 운영 프로필이 실제 승인된 환경에서만 Batch를 게시할 수 있다.
5. 실행 결과·보류 사유를 항목별로 기록하고, 이후 수정·이의제기 때 해당 콘텐츠를 재검토한다.
6. **이번 템플릿을 작성하거나 도상 시뮬레이션을 수행한 것만으로 G4/G5/G6가 PASS되지 않는다.**
