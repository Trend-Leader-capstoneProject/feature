Endpoint
- POST /api/auth/login

Request
- login_id: string
- password: string

Success
- 200 OK

Response data
- access_token: string
- token_type: "Bearer"
- user:
    user_id
    login_id
    name
    status
- has_selected_interests: boolean
- next_step: "MAIN" | "INTEREST_SELECTION"

JWT
- algorithm: 현재 Settings 사용
- sub: str(user_id)
- exp: access_token_expire_minutes 기준

Refresh Token
- 사용하지 않음

Password Hash
- pwdlib + Argon2

DB 접근
- UserRepository.find_by_login_id()
- InterestRepository.exists_by_user_id()

Service
- AuthService.login()

Token 저장
- Expo SecureStore에 access_token만 저장

인증 실패
- 401
  - 아이디/비밀번호 세부 실패 원인을 외부에 구분해서 노출하지 않음
