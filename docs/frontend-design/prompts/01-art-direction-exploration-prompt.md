문서 유형: Prompt Template
실행 시점: 프로젝트 디자인 방향을 결정할 때 1회
입력: 서비스 정의, 브랜드 자료, 사용자 대상
출력: 아트 디렉션 후보 3개와 비교 결과
주의: 출력 결과를 이 파일에 덮어쓰지 않음


React Native 기반 모바일 앱 ‘Trend Leader’의 UI/UX 아트 디렉션 후보를 탐색해주시기 바랍니다.


## 서비스 정의

Trend Leader는 사용자가 선택한 관심 분야를 기준으로 지금 떠오르는 트렌드를 발견하고, 트렌드의 배경과 흐름을 빠르게 이해하도록 돕는 개인화 트렌드 관측 도구입니다.

핵심 기능은 다음과 같습니다.

* 관심 카테고리 기반 맞춤 트렌드
* 전체 최신 이슈
* 트렌드 순위와 변화량
* 기본 요약
* AI 한 줄 요약과 유행 이유
* 관련 키워드와 출처
* 북마크

## 디자인 명제

“흩어진 트렌드 신호를 포착하고, 사용자가 이해할 수 있는 정보로 편집한다.”

일반적인 뉴스 피드, SNS 피드, 금융 대시보드가 아니라 편집 매거진과 데이터 관측 도구 사이의 인상을 지향합니다.

## 시각 언어 정의

### 주요 시각 언어: Signal Editorial

* 강한 타이포그래피 계층
* 비대칭 정보 배치
* 얇은 구분선과 여백을 통한 정보 분리
* 카드보다 섹션 중심의 구성
* 이미지보다 제목, 순위, 변화량, 메타데이터 우선
* 편집 기사와 데이터 목록 사이의 시각적 리듬

### 보조 시각 언어: Trend Radar

* 상승, 하락, 신규 진입과 같은 데이터 상태에만 사용
* 순위 변화량과 트렌드 강도를 숫자, 선, 점, 부호로 표현
* 전체 배경 장식이나 의미 없는 파동 효과에는 사용하지 않음
* 정보 전달 기능이 없는 시각 요소는 추가하지 않음

## 탐색 과제

동일한 정보 구조를 바탕으로 서로 다른 아트 디렉션 3가지를 제안해주세요.

각 방향은 단순히 색상만 달라서는 안 되며, 정보 계층과 레이아웃 전략이 실제로 달라야 합니다.

각 방향에 대해 다음을 작성해주세요.

1. 콘셉트 이름
2. 핵심 디자인 명제
3. 정보 계층 전략
4. 대표 트렌드 표현 방식
5. 일반 트렌드 목록 표현 방식
6. 순위와 변화량 표현 방식
7. 색상과 타이포그래피 방향
8. Trend Leader만의 고유 요소
9. React Native 구현 난이도
10. 장점과 위험 요소

마지막에는 다음 평가 기준으로 비교표를 작성해주세요.

* 브랜드 고유성
* 정보 가독성
* 실제 데이터 수용성
* React Native 구현 가능성
* 화면 확장성
* 유지보수성

3개 방향 중 가장 적합한 방향 하나를 추천하되, 아직 디자인 토큰이나 React Native 코드는 작성하지 마세요.

세부 화면 설계로 진행하기 전에 사용자가 방향을 선택할 수 있도록 여기서 결과를 종료해주세요.

## 금지 사항

* 모든 콘텐츠를 흰색 rounded card에 넣지 않음
* 보라색·파란색 그라데이션을 기본 테마로 사용하지 않음
* glassmorphism 사용 금지
* 모든 컴포넌트에 그림자 사용 금지
* 이모지를 기능 아이콘으로 사용하지 않음
* 일반적인 금융 대시보드 형태 금지
* SNS 게시물 카드 형태 금지
* Material Design 기본 컴포넌트를 그대로 배치한 인상 금지
* 실제 의미가 없는 그래프와 장식 금지
* 지나치게 낮은 정보 밀도 금지
