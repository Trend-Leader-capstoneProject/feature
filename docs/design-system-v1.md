선택한 Trend Leader 아트 디렉션을 실제 React Native 구현에 사용할 수 있는 디자인 시스템과 메인 화면 명세로 구체화해주세요.

## 선택한 방향

[이곳에 이전 단계에서 선택한 콘셉트와 사용자 피드백을 그대로 붙여넣습니다.]

## 대상 환경

* React Native + Expo
* Android 우선 모바일 앱
* 기준 화면 너비 360~412dp
* 세로 화면
* 한글 콘텐츠 중심
* Safe Area 고려
* 실제 서비스 수준의 정보 밀도 유지

## 메인 화면 범위

화면명은 RecommendedTrendsScreen입니다.

이 화면의 책임은 다음과 같습니다.

* 사용자의 관심 카테고리 표시
* 선택 카테고리 전환
* 대표 트렌드 1개 표시
* 맞춤 트렌드 순위 목록 표시
* 관심사 밖에서 크게 상승한 최신 이슈 일부 표시
* 트렌드 상세 화면 이동
* 북마크 버튼 입력 처리

목록 화면에서는 상세 AI 분석 내용을 직접 표시하지 않습니다.

* trends.summary를 목록 설명으로 사용
* one_line_summary, reason_text, related_keywords는 TrendDetailScreen의 책임
* AI 분석 상태가 필요하면 작은 상태 라벨만 허용

## 접근성 기준

* 주요 터치 영역은 최소 44×44dp
* 본문 텍스트는 14sp 미만 사용 금지
* 상승·하락은 색상만으로 구분하지 않음
* 아이콘에는 accessibilityLabel 제공
* 긴 제목은 최대 두 줄과 말줄임 처리
* 작은 화면에서도 핵심 정보가 잘리지 않아야 함
* 텍스트와 배경은 충분한 명도 대비 확보
